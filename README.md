# 🌐 Portfolio Website

A personal portfolio website built with **React.js** to showcase my projects, technical skills, and experience as a Front-End Developer. The website highlights selected projects, including an **Admin Dashboard** and **Marketplace** application, along with the technologies used and links to their repositories.

## ✨ Features

* Responsive design for desktop and mobile devices
* Modern and clean user interface
* Project showcase with descriptions and technologies
* About Me section
* Skills and technology stack
* Contact section
* Easy navigation with React Router

## 🛠️ Tech Stack

* React.js
* React Router
* SCSS/CSS
* JavaScript (ES6+)
* HTML5
* Git & GitHub

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/your-portfolio.git
   ```

2. Navigate to the project folder:

   ```bash
   cd your-portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

The application will be available at **http://localhost:3000**.
